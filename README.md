# ARDA HAIR

Trilingual storefront prototype for ARDA HAIR.

- Default language: German
- Additional languages: Turkish and English
- Current published products: 0
- Includes 22 supplied gallery images
- Responsive design for mobile, tablet, and desktop

## Vercel
This repository can be connected directly to Vercel. Because `index.html` is in the repository root, no build command is required for this static version.
